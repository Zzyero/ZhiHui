# 海报 / 主视觉提示词规范

适用于活动海报、宣传主视觉、Banner、促销图、演出/节日视觉、发布会视觉等。

## 先决判断
- 先提炼活动要素：主题概念、风格基调、主色、要放的内容块。
- 默认把海报当「画面 + 文字区」两层设计：模型出画面层，文字区留白，正文小字不进画面。

## 写作要点
概念与主视觉：
- 一句话主题概念 + 用哪个具象元素承载（灯笼、粒子光、音符…）+ 情绪基调。
- 主视觉主体内容、位置与占比；背景与主体层次；光影方向。

版面（成败关键）：
- 版式类型选一种：居中大字、上下分栏、左右分栏、四周留白居中主体、拼块。
- 明确哪些区域留空给文字，并给文字样式指令：字体气质、大小层级、对齐与颜色（用与画面反差色）。
- 画面确实要出现文字时：只放主标题级别短句（约六个词以内），逐字锁死拼写；小字正文必乱码，避免。
- 主动留白，避免元素拥挤重叠。

配色：
- 主色 + 辅色 + 强调色，来自主题而非随意；文字与背景要保证可读对比。

负面词（有负向参数才写）：乱码错字、多余小字、元素重叠、留白不足、水印、主题不符的杂乱元素。

## 输出
把提示词用英文短语按「概念 → 主视觉 → 版面与文字区 → 配色 → 风格」写成一段，写入「提示词」参数，不超过 1500 字符。比例按用途：竖版活动海报 2:3 或 3:4、横版主视觉 16:9。
