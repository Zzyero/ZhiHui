# 图片提示词总纲与场景路由

适用一切文生图 / 图生图任务（生成、编辑、局部重绘等）。先判断场景再决定怎么写：不同场景写法差异大，通用配方只是兜底。

## 第一步：先判断场景（必做）

根据用户描述命中下表，用 `read_skill` 加载对应场景技能，再严格按该技能的结构输出：

| 场景 | 用户需求特征 | 要加载的技能 |
|---|---|---|
| 人物写真 | 人像、写真、模特、证件照、头像、自拍、婚纱、古风人物 | `portrait-prompt` |
| 商品图 | 电商、产品、商品、卖点、详情页、白底、三视图 | `product-prompt` |
| 海报 | 海报、宣传、KV、主视觉、Banner、促销、活动图 | `poster-prompt` |
| 社媒配图 | 朋友圈、小红书、社媒、封面、配图、帖子、缩略图 | `social-prompt` |
| 漫画 | 漫画、条漫、分镜、四格、卡通人物、游戏素材 | `comic-prompt` |
| 信息图 | 信息图、数据可视化、流程图、示意图、知识卡 | `infographic-prompt` |
| App / 界面 | App、界面、UI、交互稿、图标、网页设计 | `appui-prompt` |

- 命中多个场景：全部加载，输出取交集规则。
- 无法归入以上任何场景（抽象插画、风景、概念图、纹理素材等）：用下面的通用配方。
- 编辑 / 改已有图（图像编辑、局部重绘、扩图）：先判断属于什么场景，按该场景技能写新内容；没有场景信息才走通用配方。
- 未加载对应技能禁止套用场景结构；拿不准就用通用配方保证内容完整。

## 第二步：通用配方（无明确场景时）

写法顺序：**主体（动作、外观、服装）+ 环境场景 + 构图视角 + 光线 + 风格 + 画质**。

- 主体先写后写环境，避免主体被背景淹没；明确主体位置与留白用途。
- 光线写清光源与氛围；风格写清风格词与色调。
- 用户未明确要求时画面不出现文字。
- 有「负向提示词」参数时写负面词：模糊、手部畸形、多余肢体、文字水印、低分辨率、噪点。

比例（对应宽/高参数）：1:1 方形；16:9 横幅；4:3 横版；3:2 照片；2:3 或 3:4 竖版卡片；9:16 手机全屏。

## 输出方式
- 提示词用英文短语、逗号分隔，一次写全，不超过 1500 字符。
- 写入工作流「提示词」参数；有负向参数写负面词；有宽/高/比例参数按上表给值。
- 直接输出可用的提示词，不要解释说明。
