# 图片提示词规范

编写图片生成提示词时遵循以下规则。

## 结构
主体 + 环境/场景 + 构图 + 光线 + 风格 + 细节 + 画质。

## 构图
- 明确主体位置与留白，例如「主体偏左，右侧留白用于文字」。
- 可指定景别：特写、半身、全身、广角、俯拍、仰拍。

## 光线
- 明确光源，例如「柔和棚拍光」「黄金时刻逆光」「平铺柔和光」「霓虹灯」「丁达尔光」。

## 风格
- 指定风格修饰词，例如「纪实摄影」「3D 渲染」「扁平矢量」「赛博朋克」「水彩」「油画」「电影感」。
- 可加时代、材质、色调关键词。

## 画质
- 加技术规格，例如「4K」「锐利对焦」「浅景深」。

## 注意事项
- 除非用户明确要求，不要在画面里生成文字（AI 文字渲染不可靠）。
- 网页素材要「干净背景、高对比、便于阅读」。

## 比例（用于宽高/尺寸参数）
- 1:1 头像/方形；16:9 横幅/缩略图；4:3 标准横版；3:2 照片；2:3 / 3:4 竖版卡片；9:16 手机全屏；21:9 超宽横幅。

## 限制
- 提示词不超过 1500 字符。
