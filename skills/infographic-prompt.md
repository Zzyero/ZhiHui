# 信息图 / 教育视觉提示词规范

适用于信息图、数据可视化、知识卡片、流程图、对比图、科普配图等把「信息」讲清楚的图像任务。

## 先决判断
- 先把用户给的信息结构化（标题、几个模块、每模块一两个要点），信息不全时宁少而准，不编造数据。
- 版面容器选一种：拼块网格、顶部横幅加分栏、时间轴、流程图、环形图组合。
- 正文小字与精确数字 AI 渲染不可靠：默认只做标题 + 图形化信息，长正文不进画面。

## 写作要点
信息架构：
- 一句话主题 + 模块数量与每个模块的角色（给标题概念即可）；写清阅读顺序（从上到下/从左到右/中心向外）。

版面与视觉：
- 用图形承载信息：图标化、图表（柱状/环形/流程/时间轴）、实物插画；能用图表达就不写数字句子。
- 版式：拼块网格（主卡最大，占三成左右）、分栏或中央辐射；卡片间距与边距留足，避免信息窒息。
- 配色克制：主题主色 + 辅色 + 强调色（不超过四色加中性色），用颜色区分层级；保证可读对比。

文字（画面必须出少量文字时）：
- 只放主标题与模块短标签（约四个词内），字体气质与层级写清；标题逐字锁死拼写，禁止自由发挥长句。
- 数据用柱状/环形图呈现，不让模型写精确数字。

负面词（有负向参数才写）：乱码正文、无意义长文字、数据错乱、元素重叠遮挡、拥挤无留白、风格混杂、水印。

## 输出
把提示词用英文短语按「信息架构 → 版面 → 配色 → 图形元素 → 标题文字」顺序写成一段，写入「提示词」参数，不超过 1500 字符。比例：网页知识卡 16:9、竖版信息图 3:4 或 9:16。
