# 漫画 / 插画 / 游戏素材提示词规范

适用于漫画页、条漫、四格/分镜、卡通人物设定、单幅插画、游戏立绘/道具/图标素材等。

## 先决判断
- 先定载体与画风：漫画页（黑白网点、分格）、条漫（竖版连续）、单幅插画、游戏立绘、游戏道具/图标。
- 角色是否要在多次生成中保持一致：若是，给出固定角色描述，多张图整段复用，不重写导致漂移。

## 写作要点
画风（先定调，一次只选一个主风格）：
- 风格：日系动漫、美漫粗线条、黑白网点、绘本水彩、扁平插画、3D 卡通、像素、国风/水墨、厚涂等，可加线条/上色方式修饰。

角色（漫画/卡通必备）：
- 角色定位 + 外观锚点：发型发色、瞳色、服装款式配色、标志性饰品、体型，这些特征固定不变。
- 当前画面的表情与动作单独描述；情绪靠表情动作传达，不用模糊形容词堆叠。
- 多格/系列图在末尾写清：所有格子内角色设计完全一致。

场景与分镜：
- 单幅：一句话场景 + 画面瞬间；主体位置、留白（对话框/标题区）。
- 多格/条漫：逐格写清（第几格、景别、人物动作、对话气泡位置），格子数量与排列方式在前。

游戏素材（道具/图标）：
- 单一主体、居中、干净背景、无装饰干扰，便于后续抠图。

负面词（有负向参数才写）：角色崩脸五官错位、多余手指四肢、描边断裂、上色出格、水印、对话框乱码字、风格混搭。

## 输出
把提示词用英文短语按上述结构写成一段或分节，写入「提示词」参数，不超过 1500 字符。比例：漫画页 16:9 或 3:2、条漫 9:16、立绘 2:3、头像/图标 1:1。
