# 音乐提示词规范

## 风格描述（逗号分隔描述符）
- 流派：Blues / Pop / Rock / Jazz / Electronic / Hip-hop / Folk / Classical / 国风…
- 情绪：Soulful / Melancholy / Upbeat / Energetic / Peaceful / Dark / Nostalgic…
- 场景：雨夜 / 夏日 / 公路 / 深夜 / 日出…
- 器乐：电吉他 / 钢琴 / 木吉他 / 合成器 / 弦乐…
- 人声：男声 / 女声 / 柔和 / 有力…
- 速度：慢速 / 中速 / 快速 / 舒缓…

示例：
- 「Soulful Blues, Rainy Night, Melancholy, Male Vocals, Slow Tempo」
- 「Upbeat Pop, Summer Vibes, Female Vocals, Energetic, Synth-heavy」
- 「Lo-fi Hip-hop, Chill, Relaxed, Instrumental, Piano」

## 歌词结构标签
用方括号组织段落：
- [Intro] / [Verse] / [Pre-Chorus] / [Chorus] / [Bridge] / [Solo] / [Outro] / [Hook]
- 和声与演唱提示用圆括号：(Ooh, yeah) / (Whispered) / (Fade out...)

## 纯音乐
- 用「instrumental / no vocals / 纯音乐 / 无歌词」表示无人声。

## 限制
- 风格提示词不超过 2000 字符；歌词 1~3500 字符。
