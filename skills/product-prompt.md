# 产品 / 电商图提示词规范

适用于电商主图、白底图、详情页、产品广告、场景图、包装展示、多角度图等以「商品」为核心的图像任务。

## 先决判断
- 用途决定形式：白底纯展示、场景融入生活、广告大片主图、详情页多角度拼图。
- 用户给了参考产品图：第一句先声明忠实还原该产品外观，不改造型、材质、颜色、标识。

## 写作要点
产品本体（最优先）：
- 写清类型、材质、光泽（哑光/亮面/金属）、颜色、细节特征与状态（未拆封、打开、内容物可见）。
- 卖点翻译成可见元素写进画面（防水→表面水珠；轻→单手托举），不要把卖点文字塞进画面。

场景与背景：
- 类型：纯色棚、白底、生活场景、纹理台面；白底图要求纯白背景、均匀光线、浅淡阴影。
- 背景与产品颜色要有对比，避免同色系糊在一起；道具逐项列出、不抢主体。

布光与构图：
- 白底图用大面积柔光；广告可侧光强调纹理、逆光突出玻璃/饮料等透光材质。
- 构图：居中全景、特写质感、俯拍平铺、多角度并排（前/侧/背）；电商主图居中占约七成画面，需文字位时说明留白方向。

负面词（有负向参数才写）：产品变形、乱入的肢体/手指、材质质感崩坏、文字乱码水印、过硬阴影、反射杂乱、比例失真。

## 输出
把提示词用英文短语按上述顺序写成一段（主体与忠实还原约束在最前），写入「提示词」参数，不超过 1500 字符。比例按用途：主图 1:1、详情页 3:4 或 4:5、广告 16:9。
