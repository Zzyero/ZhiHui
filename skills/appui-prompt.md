# App / Web 界面视觉提示词规范

适用于 App 界面、移动端截图、网页/落地页设计稿、UI 组件、图标、登录页、仪表盘等「屏幕界面」类图像任务。

## 先决判断
- 先定平台与设备：手机（竖屏 9:16 或 3:4）、平板、桌面浏览器（16:9），设备决定布局密度与导航形态。
- 界面类型：首页信息流、详情页、个人中心、登录注册、商品页、播放器、仪表盘等。
- 界面内文字：用英文短标签最稳；要中文界面时标签控制在约三个字并锁死拼写，正文段落不出现在画面。

## 写作要点
页面骨架：
- 从上到下逐节写清结构（如 顶部导航 → 搜索栏 → 主图轮播 → 内容宫格 → 底部标签栏），每节一句话。
- 导航模式选一种：底部标签栏、顶部导航、抽屉菜单、侧边栏。
- 内容形态：卡片列表、网格、单列长页。

UI 风格（一次一个主风格）：
- 风格：毛玻璃、材料设计、新拟态、极简黑白、果冻可爱、霓虹、像素复古、杂志编辑风等。
- 统一圆角与阴影语言（大圆角柔和或硬朗直角），间距与对齐成网格，全屏组件语言一致，禁止混搭。

配色与内容：
- 主色（品牌色）+ 辅色 + 强调色；有操作元素时写语义色（成功/警示/危险）。
- 明暗模式明确指定（深色或浅色）；文字与背景对比可读。
- 组件按需写：头像、按钮（标签短词）、图片位（用占位图形还是场景图）、数据卡片（用柱/环图表达，少量数值锁死）。
- 图标风格统一（线性或实心，粗细与圆角一致）。

负面词（有负向参数才写）：乱码/错字、元素错位重叠、组件风格混搭、图片拉伸模糊、按钮文字溢出、多余装饰、水印。

## 输出
把提示词用英文短语按「设备 → 页面骨架 → 视觉风格 → 配色 → 组件内容」顺序写成一段，写入「提示词」参数，不超过 1500 字符。用户没给细节时先用合理的现代默认风格补全完整骨架再写，不反问一堆。
