# MiniMax H3 视频提示词规范（video-prompt）

适用于所有生视频工作流（文生视频、参考图生视频、首尾帧、多图参考等）。本工作流是 MiniMax H3 系列。
读到本规范后，把用户的一句话、粗略想法、故事或对白整理成**可直接粘贴生成的中文提示词**，再调用工作流生成。

## 输入策略
- 接受：一句话创意、长提示词、故事/剧本、对白、广告创意、分镜脚本、参考图，或要求对现有提示词进行缩写/扩写/拆分/续写/修复。
- 用户不需要懂提示词术语。
- 缺信息时：能合理推断就推断并简短说明；只有缺失信息会明显改变结果时才问**最多一个**简短问题；其余直接继续。
- 永远不要声称看到了用户没提供的素材。

## 先判断生成形态（写之前静默决定）
1. 模式：文生视频 / 图生视频 / 首尾帧 / 多参考。
2. 故事类型：对白 / 动作 / 氛围 / 广告 / Vlog / 动画 / 混合。
3. 结构：单镜头连续，或一次生成内的多镜头。
4. 时长：用用户给的时长；否则选合理时长（单次生成 ≤ 15 秒）。
5. 分段：仅当故事超过单次生成容量时才拆。每段必须是一个完整微事件或情绪节拍；内容可控时优先更长更连贯的段。
- **不要**把同一个未完成的构图/姿态/动作阶段/情绪状态拆到两个独立生成里；段边界要放在景别、视角、地点、时间、主体或完成的动作发生**明显可见变化**的位置。

## 参考图规则（有参考图时）
先按上传顺序列出参考，再写提示词：
```text
图片上传顺序：
@图片1：人物主参考，锁定面容、发型、服装和体型
@图片2：场景参考，锁定空间、色彩和光线方向
```
- 只用用户确实提供的参考；冲突时说明哪张为主。
- 保留要求的身份、服装、道具、运动方向、光线、轴线与连续性。
- 忽略源图里不需要的背景、姿势、水印、界面文字与压缩噪点。

## 写可观察的指令（按此顺序）
1. 主体与**一个**核心事件。
2. 场景与连续性状态。
3. 时间线/镜头流程：具体动作、反应、终点。
4. 为故事服务的镜头运动。
5. 光线、色彩、质感与视觉风格。
6. 对白、口型、环境声、动作声与音乐。
7. 稳定性与防错约束。

- 用**可见、可生成**的描述；把「震撼 / 高级 / 电影感」这类空泛词换成具体的构图、运动、色彩、光线、节奏与质感。
- 单镜头动作负载要低，保证能稳定生成。
- 动作：说清方向、重心、起因、反应、与环境的互动和结束姿态。
- 对白：说清视线、呼吸、停顿、微表情、语气、**确切对白**与口型同步。
- 转场：找可见的衔接元素，不要只写「丝滑转场」。

## 镜头运动命令（方括号内）
- [Truck left] / [Truck right]：左右横移
- [Push in]：推近 / [Pull out]：拉远
- [Pan left] / [Pan right]：左右摇镜
- [Tilt up] / [Tilt down]：上下摇镜
- [Pedestal up] / [Pedestal down]：升降
- [Zoom in] / [Zoom out]：变焦
- [Static shot]：静止镜头
- [Tracking shot]：跟随主体
- [Shake]：手持晃动

## 默认输出格式
简单请求只输出：
```text
【任务设定】
时长｜比例｜模式｜核心事件

【图片上传顺序】
仅在有参考图时输出

【MiniMax H3 主提示词】
完整、可复制的中文生产提示词

【防错约束】
简短列出最相关的限制
```
故事/剧本/超长输入时输出分段结构：
```text
【整体设定】
角色、场景、画面、声音和跨段连续性锚点

【第1段｜时长｜完整事件名称】
图片引用
H3 主提示词
尾帧状态与下一段切点

【第2段｜时长｜完整事件名称】
...
```
- 不机械添加没价值的段落；用户只要最终提示词就省略解释。
- 需双语时给出中英对照，对白保留原语言。

## 声音与文字规则
- 除非用户要求改写，对白原文一字不改；说明谁在何时、以何种情绪说，停顿与口型同步。
- 区分画面内的环境声/动作声与画外音乐。
- 默认不加字幕、标题、logo、水印或屏幕文字；要加时给确切内容、位置、出现与消失时机。

## 防错约束
- 只加与场景相关的约束。常见失败：身份漂移、换脸、换装、道具重复、畸形手/多指、斗鸡眼、口型错位、瞬移动作、轴线反转、镜头跳变、光线不一致、多余文字、风格漂移。
- 不承诺必然成功；输入过载时减少同时动作、简化镜头，或在真实视觉边界处拆分。
- 提示词总量控制在单次生成可承受范围（参考：不超过 2000 字符）。
